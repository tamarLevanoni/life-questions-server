# דרישות לחיפוש הסיפורים

## מטרת החיפוש

לעזור למשתמש לגלות מבחר סיפורים שימושיים לכוונתו, גם כשהשאלה כללית, עמומה, כוללת שגיאות כתיב או משתמשת בניסוח שונה מזה שמופיע במאגר.

| סוג הבקשה | יכולת נדרשת |
|---|---|
| נושא או סוגייה | לאתר סיפורים שמדגימים את הנושא בכמה מקרים מעשיים |
| תיאור מקרה מחיי היום־יום | לזהות את הפעולה, התפקידים והעיקרון שעשוי לקשר למקרים במאגר |
| מראה מקום | להבין צורות כתיבה שונות ולאתר מקורות בקשרים המובנים ובטקסטים |
| שאלה כללית או מילים בודדות | להתחשב בכמה פירושים סבירים ולהציג מבחר מתאים |
| שגיאות כתיב וקיצורים | לפענח את הכוונה תוך שמירה על פרטים מהותיים |
| כותרת מלאה או חלקית | לאתר את הסיפור לפי הטקסט שהמשתמש זוכר |
| שילוב של מקרה, נושא ומקור | להציג קודם סיפורים שמתאימים גם לתוכן וגם למקור, ולכלול גם התאמות טובות לכל אחד מהם בנפרד |

## איכות ומקורות

- התאמה טובה היא מקרה שעונה לבקשה או מאיר את אותו עיקרון. דמיון במילים או בשם החפץ לבדו אינו מספיק.
- יש לשמור על פרטים שמשנים את ההתאמה, ובהם מי עשה מה, סדר האירועים, שלילה ותנאים מפורשים. השאלה המקורית נשארת בסיס לבדיקת ההתאמה גם כשנעשה שימוש בניסוח נוסף.
- תוצאות קרובות יקבלו סימון מתאים. כשאין מספיק התאמות מועילות, מציגים את מה שנמצא בלי להשלים את הרשימה בסיפורים בעלי קשר חלש.
- מתחילים במראה המקום המדויק. בהיעדר התאמה מועילה מרחיבים לכל הסימן או הדף ואז ליחידות סמוכות באותו חיבור. מסננים שנבחרו בממשק חלים בכל שלב.
- מקור שמופיע רק בהרחבה צריך להיות ניתן לאיתור. הרחבה יכולה להזכיר כמה מקורות כחלק מדיון אחד.

## חוזה חיפוש ותצוגה

- חיפוש חדש דורש שאילתה או לפחות מסנן אחד. כשנשלחת שאילתה, היא מכילה לפחות שלושה תווים כפי שהם מוצגים למשתמש, אחרי הסרת רווחי קצה. המגבלה העליונה היא 500 יחידות UTF-16 לפני הסרת הרווחים, לפי מדידת `length` ב־JavaScript. חיפוש באמצעות מסננים בלבד משמיט את השאילתה.
- החיפוש הראשון קובע את קבוצת התוצאות ואת סדרן. טעינת עמוד נוסף משתמשת בסמן המשך מתוך אותה רשימה בלי אחזור או דירוג מחדש.
- גודל העמוד אינו מגביל את מספר ההתאמות הכולל. חיפוש רחב כמו ״השבת אבידה״ יכול להחזיר את כל הסיפורים המתאימים לנושא שנמצאו בתחום המסננים.
- הממשק מסביר כשהחיפוש נמשך או כשהוחזרו תוצאות חלקיות. טקסט שלא פוענח כהפניה נשאר בחיפוש לפי תוכן.
- תוכן ההרחבה יכול לסייע באיתור סיפור. ההרשאה להציג אותו נבדקת בשרת בעמוד הסיפור.
- יעד הביצועים הראשוני הוא שלפחות 95% מהחיפושים יסתיימו בתוך שמונה שניות (p95). החיפוש יכול להמשיך מעבר ליעד. חריגות משמשות למדידה וכוונון.

## תוכן ואינדקס

- סכמת הסיפורים המקורית היא הבסיס לחיפוש. האינדקס שומר מידע שמופק מתוכן הסיפור לצורך אחזור, כמו הטקסט שנבנה מכל שדה, מודל ההטמעה וחתימת הטקסט לזיהוי שינויים.
- גוף הסיפור וההרחבה נשמרים בשלמותם בייצוגי החיפוש, ללא פיצול או חפיפה.
- שינוי בתוכן מחייב עדכון המסמך המתאים. אפשר להשתמש בווקטור קיים כשהטקסט והמודל תואמים לגרסת אינדקס תואמת.
